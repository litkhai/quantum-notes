# 핵심 용어 사전

[홈](../index.md) · [FAQ](faq.md) · [참고자료](references.md)

| 용어 | 뜻 |
|---|---|
| 양자(quantum) | 특정 물리계에서 허용되는 상태나 에너지 교환의 불연속 단위와 관련된 개념 |
| 큐비트(qubit) | 두 기준 상태의 복소 확률진폭으로 기술되는 양자정보의 기본 단위 |
| 상태(state) | 계에 대해 예측 가능한 측정 통계를 담는 수학적 표현 |
| 확률진폭(amplitude) | 절댓값 제곱이 측정 확률이 되는 복소수 계수 |
| 위상(phase) | 복소 진폭의 각도 정보. 상대위상은 간섭에 영향을 줌 |
| 중첩(superposition) | 여러 기준 상태의 선형 결합으로 표현되는 상태 |
| 간섭(interference) | 진폭의 위상에 따라 성분이 보강되거나 상쇄되는 현상 |
| 측정(measurement) | 양자상태에서 선택한 관측량의 고전 결과를 얻는 과정 |
| 기저(basis) | 상태를 성분으로 표현하거나 측정 결과를 구분하는 기준 상태 집합 |
| 게이트(gate) | 이상적인 닫힌 계에서 양자상태를 가역적으로 변환하는 연산 |
| H 게이트 | 계산 기저와 `+/-` 기저 사이를 변환해 중첩과 간섭 시연에 쓰는 게이트 |
| 텐서곱(tensor product) | 여러 양자계의 결합 상태공간을 구성하는 수학 연산 |
| 얽힘(entanglement) | 복합 상태를 각 부분의 독립 상태 곱으로 분해할 수 없는 성질 |
| 탈결맞음(decoherence) | 환경과의 상호작용으로 관측 가능한 위상 일관성이 손실되는 현상 |
| 오라클(oracle) | 입력의 특정 성질을 진폭이나 보조 레지스터에 결맞게 표시하는 추상 연산 |
| Grover 알고리즘 | 비정형 탐색의 질의 횟수를 `O(N)`에서 `O(√N)`으로 줄이는 알고리즘 |
| QFT | 양자 푸리에 변환. 주기·위상 정보를 측정 가능한 분포로 바꿈 |
| Shor 알고리즘 | 주기 찾기를 이용해 소인수분해와 이산로그를 효율적으로 푸는 알고리즘 |
| QPU | 양자 회로를 실행하는 양자처리장치 |
| 물리 큐비트 | 실제 원자·이온·회로 등으로 구현한 원시 큐비트 |
| 논리 큐비트 | 오류 정정 코드로 여러 물리 자유도에 인코딩한 계산 단위 |
| 충실도(fidelity) | 실제 상태나 연산이 목표와 얼마나 가까운지 나타내는 지표 |
| 코드 거리(distance) | 오류 정정 코드가 구분·정정할 수 있는 오류 규모와 관련된 지표 |
| 신드롬(syndrome) | 논리 정보를 직접 읽지 않고 오류 위치·종류를 추정하는 측정 정보 |
| 임계값(threshold) | 그 아래의 물리 오류율에서 코드 확장으로 논리 오류를 줄일 수 있는 경계 |
| fault tolerance | 일부 물리 오류가 발생해도 오류가 통제되지 않게 퍼지지 않도록 계산하는 성질 |
| NISQ | 오류 정정이 충분하지 않은 중간 규모 잡음 양자 장비의 시대·범주 |
| 오류 완화 | 여러 잡음 실행과 후처리로 더 나은 추정값을 얻는 방법 |
| 양자 우위 | 특정 과제에서 알려진 고전 방법보다 양자 장비가 계산 자원상 앞서는 상황 |
| 양자 유용성 | 과학·산업적으로 의미 있는 문제에서 실질적 가치를 제공하는 상태 |
| QRNG | 양자 측정을 엔트로피원으로 사용하는 난수 생성기 |
| QKD | 양자 상태의 교란을 이용해 도청 가능성을 탐지하는 키 분배 기술 |
| PQC | 양자 공격에도 강하도록 설계되어 고전 컴퓨터에서 실행되는 공개키 암호 |
| shot | 같은 회로를 한 번 실행하고 측정 결과를 얻는 단위 |
| transpilation | 논리 회로를 장비의 게이트와 연결성에 맞게 변환·최적화하는 과정 |
| 블로흐 구면(Bloch sphere) | 한 큐비트 순수상태를 구면 위의 점으로 표현하는 시각화 |
| 전역위상(global phase) | 상태 전체에 공통으로 곱해지며 측정 통계에 영향을 주지 않는 위상 |
| 상대위상(relative phase) | 상태 성분 사이의 위상 차이로 간섭 결과를 바꾸는 정보 |
| 유니터리(unitary) | 내적과 확률을 보존하는 가역 선형 연산 |
| 밀도행렬(density matrix) | 순수상태, 고전적 혼합과 부분계 상태를 함께 표현하는 행렬 |
| 순수상태(pure state) | 하나의 상태벡터로 완전히 표현되는 양자상태 |
| 혼합상태(mixed state) | 여러 준비 상태의 고전적 확률 혼합 또는 환경을 무시한 부분계 상태 |
| 관측량(observable) | 측정 가능한 물리량을 나타내는 Hermitian 연산자 |
| 기대값(expectation value) | 같은 측정을 반복했을 때 결과 평균으로 추정하는 관측량 값 |
| POVM | 잡음 있는 검출과 일반 측정을 포함하는 양의 연산자 값 측정 |
| 상태 토모그래피 | 여러 기저의 측정 통계로 양자상태를 재구성하는 절차 |
| 안정자(stabilizer) | 코드 상태를 고정하는 Pauli 연산자 또는 이를 이용한 회로 형식 |
| Clifford 게이트 | Pauli 연산자를 Pauli 연산자로 보내며 안정자 형식으로 다룰 수 있는 게이트군 |
| T 게이트 | 범용 계산에 필요한 대표 비-Clifford 위상 게이트 |
| magic state | fault-tolerant 비-Clifford 연산에 주입하는 특수한 논리 상태 |
| 디코더(decoder) | 반복 측정한 신드롬에서 오류와 복구 동작을 추정하는 고전 알고리즘 |
| 누설(leakage) | 물리 큐비트가 계산에 사용하는 두 준위 밖의 상태로 이동하는 오류 |
| 누화(crosstalk) | 한 큐비트의 제어가 주변 큐비트나 채널에 의도치 않은 영향을 주는 현상 |
| `T₁` | 들뜬 상태의 에너지가 감쇠하는 특성 시간 |
| `T₂` | 중첩 성분 사이의 위상 일관성이 감소하는 특성 시간 |
| 네이티브 게이트 | 특정 하드웨어가 물리적으로 직접 구현하도록 보정된 게이트 집합 |
| 회로 깊이(circuit depth) | 병렬 실행 가능한 게이트를 층으로 묶었을 때 필요한 순차 단계 수 |
| 동적 회로(dynamic circuit) | 중간 측정 결과에 따라 뒤의 게이트를 고전적으로 선택하는 회로 |
| 피드포워드(feed-forward) | 측정·디코딩 결과를 이후 제어 동작에 반영하는 과정 |
| 진폭 증폭 | 좋은 상태의 진폭을 반복 회전으로 키우는 알고리즘 틀 |
| 양자 위상 추정(QPE) | 유니터리 고유값의 위상을 비트열로 추정하는 알고리즘 |
| VQE | 파라미터화 양자회로와 고전 최적화로 에너지 기대값을 낮추는 변분 알고리즘 |
| QAOA | 목적함수와 혼합 해밀토니안을 교대로 적용하는 변분 최적화 알고리즘 |
| QUBO | 이진 변수의 이차 목적함수로 표현한 최적화 형식 |
| readout mitigation | 측정 오류 모델을 이용해 관측된 출력 분포의 편향을 보정하는 방법 |
| post-selection | 특정 검사 조건을 만족한 실행 결과만 분석에 사용하는 방법 |
| 양자 어닐링 | 시간에 따라 해밀토니안을 변화시켜 낮은 에너지 해를 찾는 계산 방식 |
| crypto-agility | 암호 알고리즘과 키 체계를 정책에 따라 교체할 수 있는 시스템 능력 |
| ML-KEM | NIST FIPS 203에 정의된 모듈 격자 기반 키 캡슐화 메커니즘 |
| ML-DSA | NIST FIPS 204에 정의된 모듈 격자 기반 디지털 서명 알고리즘 |
| SLH-DSA | NIST FIPS 205에 정의된 상태 비저장 해시 기반 디지털 서명 알고리즘 |
| harvest now, decrypt later | 현재 암호문을 수집해 미래의 공격 능력으로 복호하려는 위협 모델 |
| 양자 자원 추정 | 논리 알고리즘을 코드·오류율·시간 가정에 따라 물리 자원으로 환산하는 과정 |
| magic state factory | 오류가 낮은 magic state를 반복 생산·증류하는 논리 회로 영역 |
