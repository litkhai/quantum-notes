# 핵심 용어 사전

[홈](../index.md) · [FAQ](faq.md) · [참고자료](references.md)

| 용어 | 뜻 |
|---|---|
| 양자(quantum) | 특정 물리계에서 허용되는 상태나 에너지 교환의 불연속 단위와 관련된 개념 |
| 큐비트(qubit) | 두 기준 상태의 복소 확률진폭으로 기술되는 양자정보의 기본 단위 |
| 상태(state) | 계에 대해 예측 가능한 측정 통계를 담는 수학적 표현 |
| 확률진폭(amplitude) | 절댓값 제곱이 측정 확률이 되는 복소수 계수 |
| 위상(phase) | 복소 진폭의 각도 정보. 상대위상은 간섭에 영향을 줌 |
| 중첩(superposition) | 여러 기준 상태의 선형 결합으로 표현되는 상태 |
| 간섭(interference) | 진폭의 위상에 따라 성분이 보강되거나 상쇄되는 현상 |
| 측정(measurement) | 양자상태에서 선택한 관측량의 고전 결과를 얻는 과정 |
| 기저(basis) | 상태를 성분으로 표현하거나 측정 결과를 구분하는 기준 상태 집합 |
| 게이트(gate) | 이상적인 닫힌 계에서 양자상태를 가역적으로 변환하는 연산 |
| H 게이트 | 계산 기저와 `+/-` 기저 사이를 변환해 중첩과 간섭 시연에 쓰는 게이트 |
| 텐서곱(tensor product) | 여러 양자계의 결합 상태공간을 구성하는 수학 연산 |
| 얽힘(entanglement) | 복합 상태를 각 부분의 독립 상태 곱으로 분해할 수 없는 성질 |
| 탈결맞음(decoherence) | 환경과의 상호작용으로 관측 가능한 위상 일관성이 손실되는 현상 |
| 오라클(oracle) | 입력의 특정 성질을 진폭이나 보조 레지스터에 결맞게 표시하는 추상 연산 |
| Grover 알고리즘 | 비정형 탐색의 질의 횟수를 `O(N)`에서 `O(√N)`으로 줄이는 알고리즘 |
| QFT | 양자 푸리에 변환. 주기·위상 정보를 측정 가능한 분포로 바꿈 |
| Shor 알고리즘 | 주기 찾기를 이용해 소인수분해와 이산로그를 효율적으로 푸는 알고리즘 |
| QPU | 양자 회로를 실행하는 양자처리장치 |
| 물리 큐비트 | 실제 원자·이온·회로 등으로 구현한 원시 큐비트 |
| 논리 큐비트 | 오류 정정 코드로 여러 물리 자유도에 인코딩한 계산 단위 |
| 충실도(fidelity) | 실제 상태나 연산이 목표와 얼마나 가까운지 나타내는 지표 |
| 코드 거리(distance) | 오류 정정 코드가 구분·정정할 수 있는 오류 규모와 관련된 지표 |
| 신드롬(syndrome) | 논리 정보를 직접 읽지 않고 오류 위치·종류를 추정하는 측정 정보 |
| 임계값(threshold) | 그 아래의 물리 오류율에서 코드 확장으로 논리 오류를 줄일 수 있는 경계 |
| fault tolerance | 일부 물리 오류가 발생해도 오류가 통제되지 않게 퍼지지 않도록 계산하는 성질 |
| NISQ | 오류 정정이 충분하지 않은 중간 규모 잡음 양자 장비의 시대·범주 |
| 오류 완화 | 여러 잡음 실행과 후처리로 더 나은 추정값을 얻는 방법 |
| 양자 우위 | 특정 과제에서 알려진 고전 방법보다 양자 장비가 계산 자원상 앞서는 상황 |
| 양자 유용성 | 과학·산업적으로 의미 있는 문제에서 실질적 가치를 제공하는 상태 |
| QRNG | 양자 측정을 엔트로피원으로 사용하는 난수 생성기 |
| QKD | 양자 상태의 교란을 이용해 도청 가능성을 탐지하는 키 분배 기술 |
| PQC | 양자 공격에도 강하도록 설계되어 고전 컴퓨터에서 실행되는 공개키 암호 |
| shot | 같은 회로를 한 번 실행하고 측정 결과를 얻는 단위 |
| transpilation | 논리 회로를 장비의 게이트와 연결성에 맞게 변환·최적화하는 과정 |
