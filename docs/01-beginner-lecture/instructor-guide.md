# 2시간 세션 강사용 가이드

[세션 홈](README.md) · [120분 진행표](runsheet.md) · [슬라이드 구성안](slide-outline.md) · [산업·시장 브리프](industry-market-brief.md)

## 강의 목표

수강생이 수식이나 프로그래밍을 익히는 것이 아니라 다음 판단 틀을 갖게 하는 것이 목표다.

1. 양자 계산의 핵심을 중첩이 아닌 **위상·간섭·문제 구조**로 설명한다.
2. 이론적 가속, 실제 하드웨어 성능과 경제적 가치를 구분한다.
3. 하드웨어 방식과 산업 가치사슬을 하나의 시장으로 연결한다.
4. 양자 우위, 유용성, 상업적 우위를 서로 다른 이정표로 본다.
5. 기업 발표와 시장 전망의 증거 수준을 평가한다.
6. 조직이 지금 할 수 있는 준비와 아직 기다려야 할 투자를 구분한다.

## 설명 수준

- 행렬 계산은 하지 않는다.
- 큐비트 상태식은 한 번만 보여주고 의미만 설명한다.
- Grover는 수식 증명 대신 `N → √N`과 오라클 비용을 설명한다.
- Shor는 주기 찾기와 공개키 암호 영향까지만 다룬다.
- 얽힘은 “전체 상태를 부분의 독립 상태로 분해할 수 없음”으로 설명한다.
- 산업 수치는 반드시 기준일과 출처를 함께 표시한다.

## 세션의 두 축

### 1부: 이론과 한계

```text
비트와 큐비트
  → 중첩·위상·간섭
  → 얽힘
  → 알고리즘이 이용하는 구조
  → 양자 가속이 성립하는 조건
```

이론 파트의 목적은 수강생을 물리학자로 만드는 것이 아니라, 후반부의 산업 주장을 판단할 최소 언어를 제공하는 것이다.

### 2부: 산업과 시장

```text
하드웨어 방식
  → 오류 정정과 로드맵
  → 산업 가치사슬
  → 수익 모델과 구매자
  → 유즈케이스 성숙도
  → 시장 전망과 위험
```

기업 이름 나열보다 **누가 어떤 병목을 해결하고 누가 비용을 지불하는지**를 설명한다.

## 권장 시간 배분

| 블록 | 시간 | 비중 |
|---|---:|---:|
| 문제 정의와 역사 | 10분 | 8% |
| 핵심 이론 | 28분 | 23% |
| 알고리즘과 한계 | 17분 | 14% |
| 휴식 | 10분 | 8% |
| 하드웨어·오류 정정 | 18분 | 15% |
| 산업 가치사슬·기업 | 15분 | 13% |
| 시장·유즈케이스·수익 모델 | 15분 | 13% |
| 보안·전망·정리 | 7분 | 6% |

강의와 토론의 비중을 높이기 위해 라이브 데모 시간은 배정하지 않는다. 정적 도식으로 설명하기 어려운 경우에만 30초 이내의 사전 녹화 영상을 사용한다.

## 준비물

- 26장 내외의 슬라이드
- 진폭과 간섭을 보여주는 정적 3단계 그림
- 세 하드웨어 방식 비교표
- 산업 가치사슬 그림
- “검증된 결과 / 기업 목표 / 시장 전망” 3열 표
- QED-C 시장 추정치의 정의와 기준일
- 모든 기업 수치의 1차 출처

필요하지 않은 것:

- 편광판이나 실험 장비
- 실시간 회로 시뮬레이터
- 클라우드 QPU 계정
- 코딩 환경과 학생 노트북

## 강의 원칙

### 이론을 과장하지 않는다

- “모든 답을 동시에 계산한다”로 끝내지 않는다.
- 중첩을 만들었다고 계산 이득이 생기는 것은 아니라고 바로 보정한다.
- Grover의 제곱근 가속과 Shor의 큰 가속을 구분한다.
- 데이터 입력, 오류 정정과 고전 전후처리를 전체 비용에 포함한다.

### 시장을 주가 설명으로 만들지 않는다

- 공개기업 주가나 단기 밸류에이션을 강의의 근거로 사용하지 않는다.
- 기업 로드맵은 현재 성능과 분리한다.
- 시장 규모는 조사기관의 정의와 예측으로 표시한다.
- 기술 가치, 공급자 매출과 최종 사용자의 경제 가치를 구분한다.

### 회사보다 가치사슬을 먼저 가르친다

```text
부품·소재
  → QPU·제어 시스템
  → 소프트웨어·컴파일러
  → 클라우드·HPC 통합
  → 응용 솔루션·컨설팅
  → 최종 사용자
```

이후 각 위치에 대표 기업을 배치하면 회사 목록이 산업 구조로 이해된다.

## 강의 직전 업데이트

다음 항목만 강의 1주 전에 다시 확인한다.

1. QED-C의 최신 시장 매출 추정과 전망
2. 공개적으로 접근 가능한 QPU와 클라우드 가격
3. 주요 하드웨어 기업의 실제 제공 시스템
4. 오류 정정과 양자 우위의 최신 동료평가 결과
5. NIST PQC 표준과 전환 지침

## 수강생에게 남길 판단식

```text
산업적 가치
= 해결 가능한 문제의 가치
× 고전 대비 성능 차이
× 결과의 검증 가능성
× 시스템 가용성
− 전체 실행·통합·전환 비용
```

수식은 정량 모델이 아니라 누락되는 요소를 막는 체크리스트다.
