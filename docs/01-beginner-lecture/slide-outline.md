## 산업 가치사슬 슬라이드

```text
Enabling tech       Hardware          Platform          Applications
냉각·레이저·제어 → QPU·시스템 → 컴파일러·클라우드 → 화학·금융·보안
```

각 층 아래에는 역할을 대표하는 기업 2~4개를 예시로 둔다.

## 시장 슬라이드 주의사항

- `2026년 8월 기준`을 표시한다.
- QED-C의 14억 달러는 2025년 **시장 매출 추정치**라고 쓴다.
- 30억 달러는 2028년 **전망치**라고 쓴다.
- 장기 경제 가치와 상장사 시가총액은 별도의 지표로 다룬다.
- 전망을 제시한 뒤 정부 자금 의존성과 quantum winter 위험을 같은 슬라이드에 둔다.

## 시각 자료 원칙

- 복잡한 회로 대신 원리 도식 사용
- 한 슬라이드에 메시지 하나
- 기업 로고보다 방식·역할·근거를 크게 표시
- 검증된 결과는 실선, 목표는 점선으로 고정
- 시장 추정은 숫자 옆에 조사기관·연도·정의를 표시
- “가능”, “실증”, “제품”, “경제성”에 서로 다른 색 사용

## 90분으로 줄일 때

- 역사 6→3분
- 얽힘 5→3분
- 알고리즘 비교 13→9분
- 하드웨어 18→13분
- 기업 지도와 수익 모델 통합 20→13분
- 시장 규모와 유즈케이스 통합 13→8분
- 휴식 10→5분

## 3시간으로 늘릴 때

- 측정과 얽힘의 이론 15분
- 오류 정정 코드와 논리 게이트 15분
- 클라우드 가격·호환성·HPC 통합 10분
- 기업 사례 비교 10분
- 조직별 quantum readiness 워크숍 10분
