# 양자컴퓨팅 상세 심화 과정

[전체 홈](../index.md) · [입문 강의 본문](../01-beginner-lecture/lecture-notes.md) · [2시간 입문 강의](../01-beginner-lecture/README.md) · [FAQ](../03-reference/faq.md)

이 과정은 2시간 입문 강의에서 생략한 원리, 수식, 알고리즘의 한계, 하드웨어와 산업 근거를 자세히 다룬다.

## 대상

- 입문 강의를 듣고 “왜 그런가?”를 더 알고 싶은 사람
- 양자컴퓨팅을 기술적으로 평가해야 하는 개발자·연구자·산업 관계자
- 알고리즘과 하드웨어 기업의 주장을 직접 구분하고 싶은 사람

복소수와 선형대수를 알면 편하지만 각 문서에서 필요한 개념을 다시 설명한다.

## 장별 학습 목표

### 1장 · 양자이론의 출발

- 플랑크의 양자화에서 상태벡터까지의 역사적 흐름을 설명한다.
- 상태·유니터리·텐서곱·측정의 네 규칙을 계산 언어로 연결한다.
- 가역 오라클과 uncomputation이 필요한 이유를 설명한다.

### 2장 · 큐비트·게이트·측정

- 확률진폭의 크기와 상대위상을 구분한다.
- 순수상태와 혼합상태를 밀도행렬로 비교한다.
- 측정 기저, 기대값, shots와 토모그래피 비용을 설명한다.

### 3장 · 위상·간섭과 Grover

- `H-H`와 `H-Z-H` 회로의 출력 차이를 계산한다.
- 진폭 증폭을 이차원 회전과 성공확률 식으로 설명한다.
- 질의 복잡도와 전체 실행 시간의 차이를 자원 항목으로 나눈다.

### 4장 · 텐서곱과 얽힘

- 분리 가능 상태와 Bell 상태를 수식으로 판별한다.
- Schmidt 계수와 얽힘 엔트로피의 의미를 이해한다.
- Bell 상관관계, 텔레포테이션과 오류 정정의 연결을 설명한다.

### 5장 · 물리 구현과 오류 정정

- 초전도·포획 이온·중성원자·광자 방식의 시스템 병목을 비교한다.
- 물리 오류, 신드롬, 코드 거리와 논리 오류율을 연결한다.
- 논리 알고리즘에서 물리 큐비트·시간까지의 자원 추정 흐름을 읽는다.

### 6장 · 클라우드·산업·양자 우위

- 클라우드 작업의 전체 생애주기와 비용 항목을 설명한다.
- 부품·회로·논리·응용 벤치마크를 구분한다.
- 계산 우위, 유용성과 경제적 우위를 단계별로 평가한다.

### 7장 · Shor·PQC·양자 난수

- Shor의 주기 찾기와 공개키 암호 영향을 연결한다.
- 장기 데이터 위험과 PQC 전환 시점을 계산한다.
- PQC, QRNG와 QKD의 위협 모델과 배포 조건을 구분한다.

### 8장 · 주요 플레이어 전략

- 기업을 물리 방식보다 병목·가치사슬·수익 모델로 비교한다.
- 실측, 제품, 로드맵과 시장 전망의 증거 수준을 구분한다.
- 기술 완성 시간과 기업의 자본 지속기간을 함께 평가한다.

## 권장 학습 방식

각 장은 다음 순서로 읽는다.

1. 첫 번째 문단과 표에서 장의 질문을 파악한다.
2. 수식의 각 기호를 앞뒤 문장과 연결한다.
3. 예시 회로나 기업 발표를 장의 판단 기준으로 다시 분류한다.
4. 장 끝에서 관련 FAQ와 용어를 확인한다.
5. 다음 세 질문에 자신의 문장으로 답한다.

```text
이 장의 핵심 메커니즘은 무엇인가?
성립에 필요한 조건은 무엇인가?
실험·제품·시장에서는 무엇을 측정해야 하는가?
```

전체 과정은 약 4~6시간의 읽기 분량이다. 수식을 직접 전개하고 참고 논문을 읽는 과정은 별도 학습 시간으로 잡는다.
