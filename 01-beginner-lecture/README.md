# 아무것도 모르는 사람을 위한 2시간 양자컴퓨팅 강의

[전체 홈](../README.md) · [수강생용 노트](learner-notes.md) · [상세 심화 과정](../02-deep-dive/README.md)

## 이 과정의 대상

- 양자역학을 배운 적이 없는 사람
- 수식이나 프로그래밍에 익숙하지 않은 사람
- 양자컴퓨팅 뉴스를 이해하고 싶은 일반인
- 기술의 가능성과 산업적 과장을 구분하고 싶은 사람

선수지식은 필요 없다. 복소수, 행렬과 텐서곱을 몰라도 강의를 따라갈 수 있게 구성한다.

## 2시간 동안 배우는 흐름

```text
편광판의 이상한 현상
  → 큐비트와 H 게이트
  → 보이지 않는 위상
  → 간섭으로 답을 키우는 Grover
  → 얽힘
  → 실제 큐비트와 오류 정정
  → 양자 우위와 산업 전망
  → Shor와 보안 전환
```

## 강의가 끝나면 답할 수 있어야 하는 질문

1. 큐비트는 왜 동전 던지기와 다른가?
2. 여러 답을 중첩하는 것만으로는 왜 빨라지지 않는가?
3. Grover 탐색은 왜 제곱근 정도만 빨라지는가?
4. 양자컴퓨터가 스마트폰 PIN을 곧바로 뚫지 못하는 이유는 무엇인가?
5. 큐비트 수만 보고 장비 성능을 판단하면 왜 안 되는가?
6. 이미 검증된 양자 우위와 상업적 가치는 어떻게 다른가?
7. RSA는 위험한데 AES는 상대적으로 덜 위험한 이유는 무엇인가?

## 이 과정에서 의도적으로 생략하는 것

- 선형대수의 엄밀한 전개
- 슈뢰딩거 방정식 풀이
- Bell 부등식 증명
- Shor 알고리즘의 회로 세부사항
- 특정 SDK 프로그래밍 실습
- 기업별 장기 투자 판단

이 내용이 궁금해지면 [상세 심화 과정](../02-deep-dive/README.md)으로 이동한다.

## 가장 중요한 세 문장

1. **중첩이 아니라 구조에 맞춘 위상과 간섭이 계산 자원이다.**
2. **큐비트 수가 아니라 신뢰할 수 있는 논리 연산이 성능이다.**
3. **과학적 실증, 기업 로드맵과 경제적 가치는 서로 다른 증거다.**
