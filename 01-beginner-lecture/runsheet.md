# 120분 강의 진행표

[입문 강의 홈](README.md) · [강사용 로드맵](instructor-roadmap.md) · [슬라이드 구성안](slide-outline.md)

- 총 120분: 1부 55분 + 휴식 10분 + 2부 55분
- 형식: 학생 실습 없이 강사 시연
- 중심 사례: Grover 진폭 증폭과 4자리 PIN
- 절대 지킬 블록: `0:30 진폭과 간섭`, `1:05 PIN 사례와 반전`

## 1부 — 원리

### 0:00–0:08 · 편광판 세 장

1. 0°와 90° 편광판으로 빛을 막는다.
2. 사이에 45° 편광판을 넣어 빛이 일부 다시 통하는 것을 보여준다.
3. “막는 것을 더 넣었는데 왜 밝아졌을까요?”라고 묻는다.

핵심 대사:

> 중간 편광판은 빛을 더 막기만 하는 필터가 아닙니다. 통과한 성분의 편광 기준을 바꿉니다. 오늘은 상태를 다루는 과정이 이후 결과를 바꾸는 수학을 계산에 쓰는 법을 보겠습니다.

정확성 주의: 이 현상은 고전 파동광학으로도 설명된다. 양자역학의 독점적 증거라고 말하지 않고, 기저에 따른 투영을 보여주는 도입으로만 사용한다.

### 0:08–0:20 · 큐비트, H와 위상

1. Quirk에서 `|0>—H—측정`으로 50/50을 보인다.
2. `|0>—H—H—측정`으로 0이 복원됨을 보인다.
3. 동전을 두 번 섞는 것과 다르다고 설명한다.
4. `H—Z—H`를 추가해 보이지 않던 상대위상이 결과를 바꾸는 것을 보인다.

핵심 대사:

> 중첩은 단순히 결과를 모르는 상태가 아닙니다. 다시 되돌릴 수 있다는 것은 확률만으로 보이지 않는 위상 정보가 보존됐다는 뜻입니다.

### 0:20–0:30 · Bell 상태와 얽힘

1. H+CNOT으로 Bell 상태를 만든다.
2. 각 큐비트는 50/50, 함께 보면 `00` 또는 `11`이라는 점을 짚는다.
3. 얽힘을 “전체 상태를 각 부분의 상태 곱으로 분해할 수 없음”으로 정의한다.
4. 초광속 통신이 아니라는 점을 한 문장으로 제한한다.

시간이 밀리면 이 블록을 5분으로 줄이고 Bell 부등식은 다루지 않는다.

### 0:30–0:48 · 진폭과 간섭 — 강의의 엔진

1. `2⁴=16`개 상태의 동일한 진폭 막대를 보여준다.
2. 오라클을 적용해 정답 막대의 부호만 뒤집는다.
3. “확률이 그대로인데 무엇이 달라졌나요?”라고 묻는다.
4. 평균에 대한 반사로 정답 진폭이 첫 회에 약 3배가 되는 것을 보인다.
5. 같은 과정을 2차원 평면의 두 반사와 회전으로 보여준다.
6. 최적 반복 횟수를 지나치면 확률이 다시 낮아지는 과회전을 보여준다.

핵심 대사:

> 양자컴퓨터가 빠른 이유는 모든 답을 한꺼번에 읽기 때문이 아닙니다. 문제 구조에 맞게 위상을 표시하고, 틀린 답의 진폭은 상쇄하고 원하는 답의 진폭은 증폭하기 때문입니다.

> 제곱근이 나오는 직접적인 이유는 진폭이 회전하며 선형으로 변하고, 측정 확률은 진폭 크기의 제곱이기 때문입니다.

시연 리듬은 `클릭 → 3초 침묵 → 설명`으로 고정한다.

### 0:48–0:55 · 구조가 없으면 모이지 않는다

주기 입력의 푸리에 변환에서는 봉우리가 생기고, 무작위 위상에서는 봉우리가 사라지는 화면을 비교한다.

> 간섭이 유용한 답으로 모이려면 문제에 이용할 구조가 있어야 합니다. 중첩 그 자체는 계산 이득이 아닙니다.

Grover는 비정형 탐색에서도 제곱근 가속을 주지만, 지수적 문제를 다항시간 문제로 바꾸지는 못한다. Shor의 큰 가속은 주기 구조를 이용한다.

## 0:55–1:05 · 휴식

## 2부 — 현실

### 1:05–1:20 · 4자리 PIN: 성공과 반전

1. 10,000개 후보를 14큐비트의 16,384개 상태에 넣는다.
2. 한 정답일 때 약 100회의 Grover 반복으로 성공 확률이 거의 1이 됨을 보인다.
3. 고전 평균 약 5,000회와 비교해 질의 횟수의 차이를 보인다.
4. “오라클은 누가 만드나요?”라는 질문으로 전환한다.

반전:

- 스마트폰이나 ATM을 중첩 상태로 질의할 수 없으므로 물리 장치를 그대로 오라클로 쓸 수 없다.
- 해시 검증을 오라클로 만들려면 해시 계산 전체를 가역 양자 회로로 구현해야 한다.
- 실제 PIN 보안은 작은 후보 공간보다 시도 제한과 장치 보안에 의존한다.
- `2¹⁰⁰ → 2⁵⁰`은 제곱근 가속 후에도 매우 크다.

> Grover에서 검증 함수는 사후 확인 절차이기 전에 회로의 일부입니다. 오라클 구현 비용까지 계산해야 실제 이득을 말할 수 있습니다.

### 1:20–1:28 · 알고리즘마다 이용하는 구조가 다르다

칠판에 세 줄을 쓴다.

```text
Grover: 후보를 판별하는 오라클 + 진폭 증폭
Shor: 모듈러 함수의 주기 + 양자 푸리에 변환
양자 시뮬레이션: 양자계의 동역학·스펙트럼
```

모든 양자 알고리즘을 “검증기를 동시에 돌린다”로 일반화하지 않는다. 양자 화학은 값싼 고전 검증이 어려워도 원리적으로 가속이 배제되지 않으며, 대신 결과 신뢰성 평가가 중요한 연구 문제가 된다.

### 1:28–1:43 · 하드웨어 비교

초전도, 포획 이온, 중성원자를 다음 지표로 비교한다.

- 단일·2큐비트 게이트 충실도
- 게이트와 측정 속도
- 결맞음 시간
- 연결성과 라우팅 비용
- 제조·냉각·광학 제어의 확장성
- 중간 측정, 리셋과 오류 정정 적합성

> 현재 플랫폼에는 여러 공학적 절충이 있습니다. 큐비트 수 하나로 승자를 고를 수 없습니다.

IonQ와 Rigetti는 서로 다른 상장 하드웨어 기업 사례로 짧게 비교한다. 최신 수치는 [산업 심화 노트](../02-deep-dive/06-cloud-industry-and-advantage.md)와 각 회사 1차 출처를 사용한다.

### 1:43–1:53 · 물리 큐비트와 논리 큐비트

1. 여러 물리 큐비트에 논리 상태를 분산한다.
2. 데이터 자체가 아니라 오류 신드롬을 반복 측정한다.
3. 물리 오류가 임계값 아래면 코드 거리를 늘려 논리 오류를 낮출 수 있다.
4. Willow의 below-threshold 표면 코드 메모리를 중요한 실증으로 소개한다.
5. 긴 알고리즘, 논리 게이트, 디코더 지연, 상관 오류와 자원 오버헤드는 여전히 남았다고 말한다.

> 오류 정정의 원리와 제한된 규모의 오류 억제는 강하게 실증됐습니다. 실용적 오류내성 계산의 비용과 규모가 해결됐다는 뜻은 아닙니다.

### 1:53–2:00 · 산업·보안·마무리

마지막 슬라이드에 네 줄만 남긴다.

1. 제한된 양자 우위 실험은 존재하지만 범용 상업적 우위는 아직 별개의 과제다.
2. 가장 자연스러운 장기 후보는 양자계 시뮬레이션이며, 최적화와 양자 ML의 범용 우위는 더 불확실하다.
3. Shor는 RSA·DH·ECC에 영향을 주므로 NIST PQC 전환은 지금 진행해야 한다.
4. 양자컴퓨터는 CPU·GPU를 대체하기보다 고전 시스템이 제어하는 특수 가속기로 발전할 가능성이 높다.

마지막 대사:

> 물리는 진짜이고 진전도 진짜입니다. 그러나 시점은 아무도 모릅니다. 과학적 결과, 기업 로드맵, 시장 전망을 같은 증거처럼 말하는 사람을 경계하세요.

## 시간이 밀릴 때

1. 얽힘 10분 → 5분
2. 구조 없음 7분 → 4분
3. 알고리즘 비교 8분 → 5분
4. 하드웨어 15분 → 10분

진폭·간섭과 PIN 반전 블록은 줄이지 않는다.
