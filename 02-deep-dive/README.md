# 양자컴퓨팅 상세 심화 과정

[전체 홈](../README.md) · [2시간 입문 강의](../01-beginner-lecture/README.md) · [FAQ](../03-reference/faq.md)

이 과정은 2시간 입문 강의에서 생략한 원리, 수식, 알고리즘의 한계, 하드웨어와 산업 근거를 자세히 다룬다.

## 대상

- 입문 강의를 듣고 “왜 그런가?”를 더 알고 싶은 사람
- 양자컴퓨팅을 기술적으로 평가해야 하는 개발자·연구자·산업 관계자
- 알고리즘과 하드웨어 기업의 주장을 직접 구분하고 싶은 사람

복소수와 선형대수를 알면 편하지만 각 문서에서 필요한 개념을 다시 설명한다.

### 원리와 수학

`01 → 02 → 04`

상태 벡터, 측정 기저, 텐서곱과 얽힘의 의미를 중심으로 읽는다.

### 알고리즘

`02 → 03 → 07`

### 하드웨어와 산업

`05 → 06 → 07`

물리 큐비트, 오류 정정, 클라우드 비용, 기업 비교와 보안 전환을 연결한다.

## 입문 강의와 심화 과정의 차이

| 2시간 입문 | 상세 심화 |
|---|---|
| 직관과 시연 중심 | 수식·조건·예외까지 설명 |
| Grover를 대표 사례로 사용 | Grover를 다른 알고리즘과 구분 |
| 플랫폼의 큰 장단점만 비교 | 지표·오류 모델·코드와 시스템 조건 비교 |
| 산업 판단 기준을 소개 | 논문·기업 발표·가격과 우위 사례를 직접 검토 |
| 보안 결론만 전달 | Shor·Grover·PQC·QRNG·QKD 계층을 분리 |
